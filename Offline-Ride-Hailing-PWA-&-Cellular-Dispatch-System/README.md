## 🛠️ Tools
- Feel free to use whichever code editor or tool you are most comfortable with (VS Code, Notepad++, etc.).

## 🚀 How to update our work
1. Pull or download the latest files before you start writing code.
2. Add your code changes.
3. Upload/push your work back to GitHub so everyone else can see it.
